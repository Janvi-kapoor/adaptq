# Security Advisory: AdapTQ 0.2.2 Snapshot Allocation

**Title:** Unvalidated Snapshot Metadata Leads to Unsafe Allocations  
**Affected versions:** AdapTQ <= 0.2.1  
**Fixed version:** AdapTQ 0.2.2  
**CVE ID:** No CVE assigned.

## Impact
A locally crafted or maliciously modified `SessionSnapshot` (`.aqss` file) could specify out-of-bounds constraints for `dim`, `n_heads`, `bits`, or `n_tokens`. During the loading phase in `SessionSnapshot::load()`, these parameters were utilized to allocate `std::vector` structures prior to boundary validation. Supplying negative capacities or extreme numerical values resulted in uncontrolled allocation failure (std::bad_alloc) or potential buffer over-reads. 

## Root Cause
The binary decoding logic inside `session_snapshot.cpp` trusted the integers pulled from the file header. It immediately invoked `resize()` on the storage buffers using these parsed sizes without verifying if they fell within structurally safe or mathematically positive limits.

## Attack Prerequisites
An attacker must be able to supply a manipulated `.aqss` session file to the host system and trigger the `ReplayEngine` or `SessionSnapshot` loader. 

## Reproduction / PoC
The following minimal PoC demonstrates the vulnerability and the fix. 

```python
import struct
import adaptq
import tempfile

def build_malformed_snapshot():
    magic = b"AQSS"
    version = 2
    n_heads = 1
    n_tokens = -50000 # Malicious payload triggering integer underflow on size calculation
    dim = 128
    bits = 4
    
    header = struct.pack("<4s i i i i i", magic, version, n_heads, n_tokens, dim, bits)
    
    with tempfile.NamedTemporaryFile(suffix=".aqss", delete=False) as f:
        f.write(header)
        return f.name

if __name__ == "__main__":
    path = build_malformed_snapshot()
    try:
        # Under <= 0.2.1: This triggers an OOM crash or unhandled C++ exception.
        # Under 0.2.2: This throws a graceful RuntimeError and aborts loading safely.
        adaptq.snapshot_info(path)
        print("Vulnerable!")
    except RuntimeError as e:
        print(f"Secured! Rejected with error: {e}")
```

## Mitigation
Upgrade to `AdapTQ >= 0.2.2`. 
The `SessionSnapshot::load()` code now implements strict bounds validation ensuring dimensions are strictly positive and capacity ranges are validated prior to any memory allocation.
